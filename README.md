# Calculator App

A simple, fast, and responsive calculator web application that works on all devices including mobile phones.

## 🚀 Quick Start

### Open on Mobile Phone
Simply visit this link on your mobile phone:
**[Open Calculator](https://jiyaanshvora.github.io/Calculator/)**

### Or scan this QR code:
```
📱 https://jiyaanshvora.github.io/Calculator/
```

## ✨ Features

- ✅ Basic arithmetic operations (+, -, ×, ÷)
- ✅ Decimal number support
- ✅ Clear (AC) and Delete (DEL) buttons
- ✅ Modern, colorful UI
- ✅ Smooth animations
- ✅ Works on desktop, tablet, and mobile
- ✅ No installation needed - just open in browser
- ✅ Works offline once loaded

## 📋 How to Use

1. **Open the link** on your phone: https://jiyaanshvora.github.io/Calculator/
2. **Enter numbers** by tapping the number buttons
3. **Select operation** by tapping +, -, ×, or ÷
4. **Enter second number**
5. **Tap =** to see the result
6. **Use AC** to clear and start over
7. **Use DEL** to remove the last digit

## 💡 Tips

- Tap **AC** to clear everything
- Tap **DEL** to remove the last number
- You can use decimal points for precise calculations
- The calculator prevents division by zero

## 📱 Mobile Optimization

This calculator is fully optimized for mobile devices:
- Touch-friendly buttons
- Large, easy-to-read display
- Responsive layout that fits any screen size
- Works in portrait and landscape modes
